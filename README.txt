JodSub 1 — macOS package

Double-click “Start JodSub.command”, then open http://127.0.0.1:8877/.

API keys are not bundled. Enter Gemini, AssemblyAI, Pixabay or Freesound keys
inside the app on each Mac. They are stored only in that Mac's browser.

This slim package includes the JodSub app, KarnSub SFX library and bundled
FFmpeg. Large local ASR checkpoints are intentionally excluded; cloud API
transcription/diarization remains available and keeps the installer portable.
